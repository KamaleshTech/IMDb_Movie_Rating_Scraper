IMDb Movie Rating Scraper

This project uses Python, Selenium and Chrome WebDriver to scrape IMDb Top 250 movie data.

Features:
- Scrapes movie title
- Release year
- IMDb rating
- Movie ranking
- Saves data to CSV
- Displays data in a simple web dashboard

Technologies Used:
- Python
- Selenium
- pandas
- webdriver_manager
- HTML
- CSS
- JavaScript
